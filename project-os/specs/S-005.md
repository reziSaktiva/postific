# S-005 · Draft Editor redesign following the Buffer pattern, Stage 1

**Docs:** ADR-155 (and addendum 2026-11-03), ADR-154, ADR-121, ADR-107, ADR-065, ADR-054, ADR-052, ADR-047, ADR-074, ADR-039, ADR-125, ADR-149, ADR-153, `product-discovery/04-ux/key-screen-patterns.md` (KSP-05, KSP-D02, KSP-D04, KSP-D05, KSP-D12), `navigation-patterns.md` (NP-D11, NP-D14), Postific design artifact (card `ScreenDraftEditorRedesain`, ADR-140)
**Tickets:** T-199 through T-207 (`tickets/v02-publishing-mvp.md`)

## Behavior

All behavior below is seen from the side of the user (Raka, Maya, Sinta, Dimas, Lara) who opens the Draft Editor as a modal from New Post, Quick Compose, or Edit draft. Data and adapter capabilities do not grow in Stage 1; one post still has one caption and one set of media.

**Channel row**

- Above the editor there is a channel row. The "+ Channels" button opens a popover containing search, "Pilih semua", a checklist (avatar, platform badge, name, connection status), and a "Hubungkan akun" link.
- The "Terakhir dipakai" shortcut re-selects a set of accounts used before; its source is the accounts of the workspace's most recent posts (all users, all statuses except `Imported`), without a migration (King Rezi's decision 2026-11-04, T-201.2). "Semua" selects all connected accounts.
- Once accounts are selected, the row collapses into avatar chips plus a "+ Tambah akun" button. Chips can be removed.
- Disconnected accounts are still shown and may be checked, with a warning and a Reconnect action. Schedule and Publish Now are not blocked because of a Disconnected account (King Rezi's approval interpretation, ADR-155 addendum B.2).
- Quick Compose from the sidebar opens the modal with the hovered account already selected (NP-D14).
- Selecting an account or typing does not trigger a network request; validation and Preview are computed on the client.

**Editor and media**

- One caption and one set of media are shared by all networks. The editor toolbar contains only "Lampirkan media"; the media area shows thumbnails and a dropzone.

**Per-network blocks**

- Each selected network has a settings block shaped as an accordion (one open, the others collapsed into a summary row). When only one account is selected, the block is always open without an accordion, and the Pinterest format and fields are inside the block.
- The Post, Reel, or Story format follows ADR-039. Invalid options are disabled following the media rules of ADR-107, ADR-121, ADR-154. Reel (Facebook and Instagram) is only available with a single video; when the media is an image, the Reel option is disabled with the message "Reel membutuhkan satu video. Ganti media dengan video, atau pilih format Post atau Story." (ADR-155 addendum B.1). This rule is also enforced on the server.
- Pinterest has board, title, and link fields inside the block.
- A yellow inline validation banner in the block shows violations per network (media required, empty board, Reel without video). Cross-network violations (Story with mixed captions, more than one Pinterest account) are shown above the editor. The rules are the same as before; only their location moved.

**Live Preview**

- The right panel shows a Preview that updates as the user types, per platform: Facebook, Instagram, TikTok, Pinterest imitate their real appearance (assembled from Postific components and tokens); other platforms use a generic card. A tab or selector per selected account switches between Previews.
- With no account selected, the Preview shows an empty state explaining what needs to be filled in. With an account selected but no caption or media, the Preview card is still shown with a caption placeholder (King Rezi's decision 2026-11-04, following the confirmed design).
- The Preview toggle in the header hides or shows the panel.

**Schedule and footer actions**

- The footer contains Save as Draft, the "Atur jadwal" button, Schedule, and Publish Now. No "Next Available" and no "Create Another".
- "Atur jadwal" opens a popover: a calendar (past days and days more than 30 days from now are disabled), a time input, a time zone label ("WIB" in the design), and an explanation of the limit. Once filled in, the button shows the schedule, e.g. "Rab, 4 Nov · 10:00 WIB". Input is still interpreted in the user's time zone (ADR-146, default WIB), so the label follows that zone; the design only shows the WIB case.
- Schedule validation messages are shown in the footer near the schedule controls.
- Save as Draft is allowed without media (ADR-125: the target accounts of the draft are saved). Schedule and Publish Now are only enabled when validation passes and the role permits it (RBAC, ADR-047, ADR-074).
- Schedule and Publish Now go through the Confirmation Summary. While the summary is shown, the Preview panel stays visible. After a terminal action, the redirect follows ADR-054.

**Edit Draft and per-status state**

- Edit Draft opens the modal with a form filled from server data, without a localStorage check (KSP-05 State Handling): caption, media, selected accounts as chips, format per account, and the saved Pinterest options (board, title, link) (ADR-125). Date and time are not filled in because they are not yet persisted on Save as Draft.
- Behavior per status follows what applies now and is not changed by the redesign: `Published`, `Failed`, and `Imported` posts are read-only and are not opened in the Draft Editor (T-091, `readonly-terminal-status`); `Scheduled` posts follow the Edit Draft behavior that applies now. The status chip in the header still shows the content status.
- The redesign must not make the result of Edit Draft or the status chip differ from before; the comparison is proven in the T-207 E2E.

**Variants and screens**

- Standard (1120px wide, default) and Fullscreen via a toggle in the header; the choice is not persisted (ADR-065).
- Resume: when a saved New Post draft exists, a modal dialog appears (KSP-05-F13) with a tidied description text, without KSP or ADR IDs in the UI. Resume only restores the caption; accounts and media do not come back.
- Narrow screen (375px): a full-screen modal with an "Editor | Pratinjau" tab under the header, a stacked footer, and the Fullscreen and Preview toggles in the header hidden.
- Dark mode: all zones, the Preview, popovers, and banners are readable using theme tokens, with no light flash.

## Test seams

- Domain `content-format-matrix` (unit tests): the Reel media type must be video, minimum media per platform and format pair.
- Domain `schedule-time-constraints` (unit tests): the 30-day upper bound and past days, including exactly at the boundary.
- Server: `scheduleDraftAction`, `publishNowAction`, and the MCP `schedule_posts` path reject Reel without video and schedules outside the bounds (unit or integration tests on the action side).
- Draft Editor components in `apps/web/src/app/(app)/components/draft-editor/` (channel row, network blocks, Preview, schedule footer, Confirmation Summary); pure functions (account selection, per-network validation results) are unit tested.
- Edit Draft and read-only status: the before and after comparison of the redesign (accounts, format, Pinterest options filled from saved data; `Published`, `Failed`, `Imported` not opened) is proven in the T-207 E2E and QA.
- Playwright E2E tests (ADR-149), folder `apps/web/e2e/`: golden path creates a draft, selects accounts, fills in caption and media, sees the Preview, sets a schedule within the bounds, Save as Draft; plus narrow screen and dark mode. Does not publish to real social media accounts (S-002).
- Final verification through the Done (code) and Verified (staging) ladder (ADR-153).

## Out of scope

- Per-network caption and media.
- First Comment, TikTok options (title, mode), and advanced Instagram options (Collaborators, Tag Products, Music, Stickers, AI disclosure).
- Tags, Templates, AI Assistant, emoji, and hashtags in the toolbar.
- Next Available and the queue slot concept.
- Create Another.
- Persistence of accounts and media on Resume (only the caption comes back).
- New storage or migration for "Terakhir dipakai" (its source is the most recent posts, with no new storage).
- Media type rules for platforms other than Facebook and Instagram Reel (e.g. YouTube must be video).
- Changes to the data model, migrations, or the Outstand adapter.
