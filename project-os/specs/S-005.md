# S-005 · Redesain Draft Editor mengikuti pola Buffer, Tahap 1

**Docs:** ADR-155 (dan addendum 2026-11-03), ADR-154, ADR-121, ADR-107, ADR-065, ADR-054, ADR-052, ADR-047, ADR-074, ADR-039, ADR-125, ADR-149, ADR-153, `product-discovery/04-ux/key-screen-patterns.md` (KSP-05, KSP-D02, KSP-D04, KSP-D05, KSP-D12), `navigation-patterns.md` (NP-D11, NP-D14), artifact desain Postific (kartu `ScreenDraftEditorRedesain`, ADR-140)
**Tiket:** T-199 sampai T-207 (`tickets/v02-publishing-mvp.md`)

## Perilaku

Semua perilaku di bawah dilihat dari sisi pemakai (Raka, Maya, Sinta, Dimas, Lara) yang membuka Draft Editor sebagai modal dari New Post, Quick Compose, atau Edit draft. Kapabilitas data dan adapter tidak bertambah di Tahap 1; satu post tetap punya satu caption dan satu set media.

**Baris channel**

- Di atas editor ada baris channel. Tombol "+ Channels" membuka popover berisi pencarian, "Pilih semua", daftar centang (avatar, badge platform, nama, status koneksi), dan tautan "Hubungkan akun".
- Pintasan "Terakhir dipakai" memilih ulang sekumpulan akun yang dipakai sebelumnya; sumbernya akun dari post terbaru workspace (semua pemakai, semua status), tanpa migrasi (keputusan King Rezi 2026-11-04, T-201.2). "Semua" memilih semua akun terhubung.
- Setelah ada akun terpilih, baris menciut menjadi chip avatar plus tombol "+ Tambah akun". Chip bisa dilepas.
- Akun Disconnected tetap tampil dan boleh dicentang, dengan peringatan dan aksi Reconnect. Schedule dan Publish Now tidak diblokir karena akun Disconnected (tafsir persetujuan King Rezi, ADR-155 addendum B.2).
- Quick Compose dari sidebar membuka modal dengan akun yang di-hover sudah terpilih (NP-D14).
- Memilih akun atau mengetik tidak memicu request jaringan; validasi dan Pratinjau dihitung di klien.

**Editor dan media**

- Satu caption dan satu set media dipakai bersama semua jaringan. Toolbar editor hanya berisi "Lampirkan media"; area media menampilkan thumbnail dan dropzone.

**Blok per jaringan**

- Tiap jaringan terpilih punya blok pengaturan berbentuk akordeon (satu terbuka, lainnya menciut jadi baris ringkas). Bila hanya satu akun terpilih, blok selalu terbuka tanpa akordeon, dan format serta field Pinterest ada di dalam blok.
- Format Post, Reel, atau Story mengikuti ADR-039. Opsi yang tidak sah dinonaktifkan mengikuti aturan media ADR-107, ADR-121, ADR-154. Reel (Facebook dan Instagram) hanya tersedia dengan satu video; bila media gambar, opsi Reel nonaktif dengan pesan "Reel membutuhkan satu video. Ganti media dengan video, atau pilih format Post atau Story." (ADR-155 addendum B.1). Aturan ini ditegakkan juga di server.
- Pinterest punya field board, judul, dan link di dalam blok.
- Banner validasi kuning inline di blok menampilkan pelanggaran per jaringan (media wajib, board kosong, Reel tanpa video). Pelanggaran lintas jaringan (Story dengan caption campur, lebih dari satu akun Pinterest) tampil di atas editor. Aturannya sama dengan sebelumnya; hanya letaknya yang pindah.

**Pratinjau live**

- Panel kanan menampilkan Pratinjau yang diperbarui saat mengetik, per platform: Facebook, Instagram, TikTok, Pinterest meniru tampilan aslinya (dirakit dari komponen dan token Postific); platform lain memakai kartu generik. Tab atau pemilih per akun terpilih berpindah antar Pratinjau.
- Tanpa akun terpilih, Pratinjau menampilkan keadaan kosong yang menjelaskan apa yang perlu diisi. Dengan akun terpilih tetapi tanpa caption atau media, kartu Pratinjau tetap tampil dengan placeholder caption (keputusan King Rezi 2026-11-04, mengikuti rancangan terkonfirmasi).
- Toggle Pratinjau di header menyembunyikan atau menampilkan panel.

**Jadwal dan aksi footer**

- Footer berisi Save as Draft, tombol "Atur jadwal", Schedule, dan Publish Now. Tanpa "Next Available" dan tanpa "Create Another".
- "Atur jadwal" membuka popover: kalender (hari lampau dan hari di atas 30 hari dari sekarang nonaktif), input jam, label zona waktu ("WIB" pada rancangan), dan penjelasan batas. Setelah diisi, tombol menampilkan jadwal, mis. "Rab, 4 Nov · 10:00 WIB". Input tetap ditafsirkan di zona waktu pengguna (ADR-146, default WIB), jadi labelnya mengikuti zona itu; rancangan hanya menunjukkan kasus WIB.
- Pesan validasi jadwal tampil di footer dekat kontrol jadwal.
- Save as Draft boleh tanpa media (ADR-125: akun tujuan draft tersimpan). Schedule dan Publish Now hanya aktif bila validasi lulus dan peran mengizinkan (RBAC, ADR-047, ADR-074).
- Schedule dan Publish Now melewati Confirmation Summary. Saat ringkasan tampil, panel Pratinjau tetap terlihat. Setelah aksi terminal, redirect mengikuti ADR-054.

**Edit Draft dan state per status**

- Edit Draft membuka modal dengan form terisi dari data server, tanpa cek localStorage (KSP-05 State Handling): caption, media, akun terpilih sebagai chip, format per akun, dan opsi Pinterest (board, judul, link) yang tersimpan (ADR-125). Tanggal dan jam tidak terisi karena belum dipersist saat Save as Draft.
- Perilaku per status mengikuti yang berlaku sekarang dan tidak diubah redesain: post `Published`, `Failed`, dan `Imported` bersifat read-only dan tidak dibuka di Draft Editor (T-091, `readonly-terminal-status`); post `Scheduled` mengikuti perilaku Edit Draft yang berlaku sekarang. Status chip di header tetap menampilkan status konten.
- Redesain tidak boleh membuat hasil Edit Draft atau status chip berbeda dari sebelumnya; pembandingnya dibuktikan di E2E T-207.

**Varian dan layar**

- Standard (lebar 1120px, default) dan Fullscreen lewat toggle di header; pilihan tidak dipersist (ADR-065).
- Resume: bila ada draft New Post yang tersimpan, muncul dialog modal (KSP-05-F13) dengan teks deskripsi yang dirapikan, tanpa ID KSP atau ADR di UI. Resume hanya mengembalikan caption; akun dan media tidak kembali.
- Layar sempit (375px): modal penuh dengan tab "Editor | Pratinjau" di bawah header, footer ditumpuk, toggle Fullscreen dan Pratinjau di header disembunyikan.
- Mode gelap: semua zona, Pratinjau, popover, dan banner terbaca dengan token tema, tanpa kedipan terang.

## Jahitan tes

- Domain `content-format-matrix` (tes unit): jenis media Reel wajib video, minimum media per pasangan platform dan format.
- Domain `schedule-time-constraints` (tes unit): batas atas 30 hari dan hari lampau, termasuk tepat di batas.
- Server: `scheduleDraftAction`, `publishNowAction`, dan jalur MCP `schedule_posts` menolak Reel tanpa video dan jadwal di luar batas (tes unit atau integrasi di sisi aksi).
- Komponen Draft Editor di `apps/web/src/app/(app)/components/draft-editor/` (baris channel, blok jaringan, Pratinjau, footer jadwal, Confirmation Summary); fungsi murni (pemilihan akun, hasil validasi per jaringan) dites unit.
- Edit Draft dan status read-only: pembandingnya sebelum dan sesudah redesain (akun, format, opsi Pinterest terisi dari data tersimpan; `Published`, `Failed`, `Imported` tidak dibuka) dibuktikan di E2E dan QA T-207.
- Tes Playwright E2E (ADR-149), folder `apps/web/e2e/`: golden path membuat draft, memilih akun, mengisi caption dan media, melihat Pratinjau, mengatur jadwal dalam batas, Save as Draft; plus layar sempit dan mode gelap. Tidak mempublikasikan ke akun media sosial nyata (S-002).
- Verifikasi akhir lewat tangga Done (code) dan Verified (staging) (ADR-153).

## Di luar spec

- Caption dan media per jaringan.
- First Comment, opsi TikTok (judul, mode) dan opsi lanjutan Instagram (Collaborators, Tag Products, Music, Stickers, AI disclosure).
- Tags, Templates, AI Assistant, emoji, dan hashtag di toolbar.
- Next Available dan konsep slot antrean.
- Create Another.
- Persistensi akun dan media pada Resume (hanya caption yang kembali).
- Penyimpanan atau migrasi baru untuk "Terakhir dipakai" (sumbernya post terbaru, tanpa penyimpanan baru).
- Aturan jenis media untuk platform selain Reel Facebook dan Instagram (mis. YouTube harus video).
- Perubahan model data, migrasi, atau adapter Outstand.
