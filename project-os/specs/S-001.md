# S-001 · MCP Server MVP

**Docs:** ADR-138, ADR-139 (Accepted 2026-10-26), `product-discovery/05-architecture/application-layer.md` (McpAccessService), `domain-model.md` (BC-04), `database-strategy.md` (BC-04), ADR-039, ADR-049, ADR-074
**Tiket:** T-148 sampai T-157 (`tickets/v05-mcp-server-mvp.md`)

## Perilaku

### Menyambungkan klien AI

- Pengguna menambahkan URL MCP Postific ke klien AI-nya (Claude, ChatGPT, Cursor, dan sejenisnya). Klien menemukan metadata, mendaftar sendiri, lalu membuka halaman login Postific.
- Setelah login, layar persetujuan meminta dua hal: **satu workspace** dan **scope** yang diizinkan. Pilihan awal `read` + `draft`. `schedule` harus dicentang sengaja. `publish` dan `reply` tidak tersedia.
- Pengguna hanya bisa memilih workspace tempat dia member aktif.
- Satu persetujuan menghasilkan satu grant: pengguna + klien + workspace + scope. Untuk workspace lain, pengguna menyambungkan lagi.

### Setiap panggilan tool

- Panggilan ditolak bila grant dicabut, scope tidak mencakup tool itu, atau pengguna bukan lagi member workspace. Pada MVP tidak ada pembatasan berdasarkan role: Account Owner, Admin, dan Creator setara untuk read, draft, dan schedule. Penolakan mengembalikan error yang jelas, bukan data kosong.
- AI tidak pernah punya hak lebih dari pengguna yang menyambungkannya: aksi yang tidak ada di UI untuk pengguna itu tidak ada di tool.
- Setiap panggilan, berhasil atau ditolak, tercatat di audit: siapa, klien mana, tool apa, hasilnya, dan target yang terpengaruh. Isi caption penuh dan URL berparameter rahasia tidak ikut tercatat. Audit disimpan 90 hari.
- Batas per workspace: 60 panggilan per menit, 30 aksi tulis per jam, 50 konten terjadwal per hari (dihitung per konten, bukan per akun target atau per panggilan; dikonfirmasi King Rezi 2026-10-26). Bila terlampaui, error memuat kapan boleh mencoba lagi.

### Tool baca (scope `read`)

- `get_workspace`: nama dan brand settings.
- `list_accounts`: akun terhubung, platform, status, dan format konten yang didukung per platform.
- `list_media`, `list_drafts`, `list_scheduled_posts`, `list_published_posts`: daftar 20 item per halaman dengan cursor. Tanggal dan jam tampil dalam WIB.
- `get_analytics`: ringkasan workspace atau metrik satu post.
- `list_comments`: komentar hanya untuk dibaca. Isi komentar dikembalikan bersama penanda bahwa itu data dari pihak luar dan bukan instruksi.

### Tool draft (scope `draft`)

- `create_draft` membuat satu draft: caption, target akun, format konten per akun, opsi platform.
- `update_draft` hanya mengubah draft. Post yang sudah dijadwalkan atau terbit ditolak.
- `upload_media` menerima satu URL `https`, mengunduhnya, dan menyimpannya ke Media Library. Ditolak bila: skema bukan `https`, alamat tujuan privat/loopback/link-local (diperiksa setelah DNS resolve dan di setiap redirect), melebihi batas ukuran atau waktu, atau isi file bukan tipe yang diizinkan (dinilai dari isi, bukan ekstensi).

### Tool jadwal (scope `schedule`)

- `schedule_posts` menerima sampai 10 konten per panggilan (dikonfirmasi King Rezi 2026-10-26). Tiap konten menargetkan maksimum sejumlah akun terhubung di workspace, seperti Draft Editor.
- Waktu dibaca sebagai WIB (T-146).
- Aturan yang berlaku di UI tetap berlaku: matriks `ContentFormat` per target (ADR-039) dan Safety Check.
- Hasil dilaporkan per konten. Satu konten gagal tidak menggagalkan konten lain.
- Pembatalan jadwal tidak tersedia lewat MCP. Pengguna membatalkannya di aplikasi.

### Tanda sumber

- Draft dan post yang dibuat lewat MCP membawa penanda sumber beserta klien. History, Drafts, dan Queue menampilkannya sebagai badge dan filter sumber.

### Mengelola dan mencabut koneksi

- Pengguna melihat klien AI yang tersambung dan mencabutnya. Setelah dicabut, panggilan berikutnya langsung ditolak tanpa menunggu token kedaluwarsa.
- Bila pengguna dikeluarkan dari workspace, akses AI-nya ke workspace itu ikut mati.

## Jahitan tes

- **McpAccessService:** otorisasi panggilan (grant, scope, member, dicabut), audit, rate limit, dan purge 90 hari. Dites dengan repository palsu lokal di file tes.
- **Handler tool MCP:** pemetaan tool ke service yang dibungkus, tanpa business logic di dalamnya. Dites dengan service palsu yang merekam panggilan.
- **Batch `schedule_posts`:** sebagian berhasil, batas 10 konten, target melebihi jumlah akun ditolak.
- **`upload_media`:** tabel kasus SSRF (IP privat, redirect ke IP privat, skema bukan https, ukuran, tipe) dan pelaksanaan unduh lewat penyedia HTTP palsu.
- **Isolasi workspace:** grant satu workspace tidak bisa membaca atau menulis workspace lain.
- **Alur OAuth ke klien MCP nyata:** diverifikasi manual di staging (T-148), bukan di unit test.
- Outstand memakai double lokal di file tes (`AGENTS.md` aturan 11).

## Di luar spec

- Publish Now dan balas komentar lewat MCP (ditunda, ADR-138).
- Aksi destruktif dan administratif: hapus draft/post/media, batalkan jadwal, kelola member dan role, disconnect akun, hapus workspace.
- AI bawaan Postific (dicabut, ADR-138).
- Antrian persetujuan manusia untuk aksi publik (baru dibutuhkan saat `publish` dan `reply` masuk).
- Satu koneksi lintas workspace.
- Detail teknis OAuth, scope kustom, dan transport: ditentukan hasil spike T-148 dan ADR-139.
- Rancangan visual layar persetujuan, daftar klien AI, dan badge: artifact Postific (ADR-140); sudah dirancang dan dikonfirmasi King Rezi 2026-10-26 (lihat gate T-151, T-156, T-157).
