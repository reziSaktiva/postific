# S-002 · QA end-to-end dengan Playwright (Chrome)

**Docs:** ADR-149, ADR-081, ADR-119, `product-discovery/06-engineering/cicd-pipeline.md` (CI-D07)
**Tiket:** T-172 sampai T-176 (`tickets/v01-foundation.md`)

## Perilaku

- Setiap tiket fitur yang selesai punya minimal satu tes E2E golden path, dan seluruh suite hijau sebelum tiket dianggap selesai (ADR-149).
- Suite dijalankan terhadap `local` atau `staging` dengan mengganti satu variabel (`E2E_BASE_URL`), memakai Google Chrome. Perintahnya satu: `bun run test:e2e` dari root.
- Tes masuk lewat akun test khusus (kredensial dari `.env.local` atau GitHub Secrets), memakai sesi tersimpan supaya login tidak diulang di tiap tes.
- Tes hanya menyentuh data milik akun test, memberi awalan `e2e-` pada data yang dibuat, dan membersihkannya. Tes tidak mempublikasikan ke akun media sosial nyata.
- Kegagalan menyimpan trace dan screenshot sebagai artifact.
- Di CI, suite jalan terhadap staging setelah deploy pada `push` ke `staging`; hasil hijau menjadi required check untuk PR `staging` → `main`.
- Untuk PR `feature/*` → `staging`, penulis tiket menjalankan suite di `local` dan menaruh hasilnya di deskripsi PR.

## Jahitan tes

- `apps/web/e2e/` (folder tes) dan `apps/web/playwright.config.ts`. Satu proyek setup untuk login, satu proyek tes Chrome.
- Tes pertama: Start Page (buat halaman, tambah tautan, publish, buka `/u/<slug>` tanpa cookie, klik tautan, counter di Page Editor). Datanya sudah teruji manual di T-164.
- Workflow `.github/workflows/e2e-staging.yml`.
- Tes unit/Vitest tetap untuk logika domain; E2E tidak menggantikannya.

## Di luar spec

- Firefox/WebKit/Safari (tiket lintas-browser tersendiri, mis. T-171.2).
- Tes yang mempublikasikan ke Outstand atau akun media sosial nyata.
- Gerbang E2E untuk PR ke `staging` di CI (ditolak di ADR-149).
- Pengaturan branch protection GitHub (dikerjakan King Rezi atau atas izin eksplisit).
- Pemicu "setelah deploy Railway selesai" sudah diputuskan di T-175.1: `push` ke `staging` + polling status deployment GitHub dari Railway.
