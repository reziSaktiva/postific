## Decision ADR-003

### Title

Framework

### Status

Accepted

### Date

2026-07-13

### Decision

Project menggunakan **Next.js** sebagai framework utama.

### Reason

- Mendukung Marketing Website dan Dashboard dalam satu aplikasi.
- Mendukung Server Components.
- SEO yang baik.
- Routing modern.
- Mudah dikembangkan.

### Alternatives Considered

- React + Vite
