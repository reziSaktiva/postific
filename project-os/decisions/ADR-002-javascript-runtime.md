## Decision ADR-002

### Title

JavaScript Runtime

### Status

Accepted

### Date

2026-07-13

### Decision

Project menggunakan **Bun** sebagai JavaScript runtime dan package manager.

### Reason

- Instalasi dependency lebih cepat.
- Startup lebih cepat.
- Workflow lebih sederhana.
- Cocok untuk project baru.

### Alternatives Considered

- pnpm
- npm
