# BRAINSTORM

This document stores ideas that come out of brainstorming sessions, including ideas that are not yet mature, alternatives that were considered, and possibilities to explore further.

> Filled in automatically by the AI whenever a brainstorming session produces an idea worth keeping.

An idea here is **not necessarily a decision**. To become a decision, an idea must go through a review process and be recorded in `DECISIONS.md`.

---

# Entry Format

```
## [YYYY-MM-DD] — [Brainstorm Topic]
**Phase:** [active phase at the time of the brainstorm]
**Context:** [why this topic was discussed]
**Ideas:**
- [idea 1]
- [idea 2]
**Evaluation:** [aligned / conflicting / needs an ADR / needs further validation]
**Next Action:** [discard / keep for phase X / create an ADR / validate first]
```
